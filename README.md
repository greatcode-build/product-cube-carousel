# Product Cube Carousel

A lightweight static product showcase built with Swiper.js and styled with modern CSS.

This demo renders a rotating 3D cube carousel of product images, perfect for ecommerce landing pages, product galleries, and interactive UI prototypes.

## Why this project is useful

- **Visual product presentation**: Displays product images with an engaging cube transition.
- **Simple, reusable structure**: Built with plain HTML, CSS, and JavaScript.
- **Easy customization**: Swap images, text, or Swiper options without a build step.
- **Static delivery**: Works as a standalone page using CDN hosted Swiper and fonts.

## Features

- 3D cube slider effect via `Swiper.js`
- Hover enabled grab cursor and seamless looping
- Responsive layout with centered product cards
- Product title and price overlay on each slide

## Getting started

### Prerequisites

- Web browser
- Internet connection for CDN-hosted Swiper and Google Fonts

### Run locally

1. Clone the repository:

```bash
git clone <repo-url>
cd product-cube-carousel
```

2. Open `index.html` in your browser.

### Recommended local server

For best results, serve the project over a local HTTP server:

```bash
cd /Users/greatlucky/Desktop/product-cube-carousel
```

## Project structure

- `index.html` — main page and Swiper markup
- `css/style.css` — layout and visual styling
- `js/main.js` — Swiper initialization and cube effect settings
- `images/` — carousel image assets

## Customization

- Replace or update slides in `index.html`
- Modify `css/style.css` to change layout, colors, or typography
- Adjust Swiper settings in `js/main.js` to change effects, looping, or behavior
